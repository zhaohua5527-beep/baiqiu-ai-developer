# ⚪ 白球 AI —— 把 AI 从「聊天窗口」带到你的电脑里

过去几年，我们已经习惯了和 AI 对话。

写文章、查资料、分析问题、生成代码……

AI 越来越聪明。

但一个问题始终存在：

**AI 给了你答案，然后呢？**

文件还是要你自己整理。

网页还是要你自己打开。

表格还是要你自己处理。

资料还是要你自己归档。

任务还是要你在人和软件之间不断复制、粘贴、切换、确认。

今天绝大多数 AI 的能力，依然停留在：

**「告诉你应该怎么做。」**

而我们想做的，是另一件事情。

---

# 白球 AI

**一个真正运行在 Windows 电脑里的个人 AI Agent。**

它不仅负责思考，也负责执行。

不仅回答问题，也能够理解目标、拆解任务、调用工具、操作本地环境，并持续把一件事情推进下去。

换句话说：

我们希望 AI 不再只是电脑里的一个聊天窗口。

而是逐渐成为电脑里的一个新的「智能执行层」。

---

## 🧠 从一句话开始，而不是从软件开始

传统电脑的工作方式是：

你先想清楚要做什么，

然后决定打开哪个软件，

再寻找对应功能，

最后一步一步完成操作。

白球 AI 希望把这个过程反过来。

你只需要告诉它：

**「我要什么结果。」**

例如：

“帮我整理一下桌面。”

“分析这几个 Excel，找出异常数据。”

“把这个文件夹里的资料总结一下。”

“搜索这个行业最近的信息，然后整理成报告。”

“帮我检查这些文件，并按照规则重新分类。”

“完成这个任务，过程中自己决定需要哪些工具。”

剩下的事情，不再完全由你手动规划。

白球会尝试理解你的目标，并围绕目标组织接下来的执行过程。

---

# ⚪ 它不是一个 Agent，而是一套 Agent 能力体系

白球并没有把所有能力塞进一个巨大的聊天机器人里。

项目正在逐渐拆分出不同的专业 Agent：

🌐 **Browser Agent**

负责与互联网、网页和在线信息交互。

🖥 **Desktop Assistant**

面向 Windows 桌面环境，让 AI 能够真正进入你的电脑工作流。

📁 **File Agent**

围绕文件查找、读取、整理、管理和处理构建能力。

📊 **Spreadsheet Agent**

针对 Excel 和结构化数据进行处理、分析和生成。

不同能力可以围绕同一个任务协同工作。

未来一个任务可能并不是由“一个 AI”完成。

而是：

**一个 AI 理解目标，多个 Agent 协同完成任务。**

---

# 🛠 Skills：让 AI 获得新的能力

白球的能力并不希望永远写死在软件内部。

通过 Skills 体系，可以逐步给 AI 增加新的专业能力。

今天它可能会整理文件。

明天可以安装一个新的 Skill，让它掌握新的工作方法。

以后甚至可以针对不同职业和工作流形成不同的能力组合：

程序员的白球

运营人员的白球

办公人员的白球

数据分析师的白球

内容创作者的白球

每个人的 AI，都不一定需要拥有完全相同的能力。

**真正的个人 AI，应该可以成长。**

---

# 🧠 Memory：不只是记住聊天记录

AI 如果每次打开都重新认识你一次，

那它始终只是一个临时工具。

个人 AI 更重要的一步，是逐渐理解：

你习惯怎么工作。

哪些事情对你重要。

你以前做过什么决定。

你的项目有哪些背景。

哪些方法曾经有效。

哪些事情以后可以做得更好。

因此白球正在把 Memory、Experience、Learning、Reflection 等能力放进整个 Agent 架构里。

我们希望未来的白球不是：

**“一个你用了很多次的 AI。”**

而是：

**“一个越来越了解怎么和你一起工作的 AI。”**

---

# ⚙️ Agent Runtime：白球不想绑定某一个 AI 内核

白球的另一个重要方向，是把「产品」和「Agent Runtime」分开。

现在已经建立 Runtime 抽象层。

OpenClaw 可以作为 Agent 内核运行。

Hermes 也可以接入。

未来新的 Agent Runtime，同样可以进入这套体系。

这意味着：

**白球本身并不一定等于某一个模型、某一家 API，甚至也不等于某一个 Agent 框架。**

模型会变化。

Agent 框架会变化。

推理技术也会变化。

但用户真正需要的桌面入口、记忆、工具、Skills、权限、工作流和数据，不应该跟着全部推倒重来。

我们希望白球最终成为承载这些能力的一层稳定产品平台。
