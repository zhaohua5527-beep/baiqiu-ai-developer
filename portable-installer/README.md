# F 盘单入口安装器

2026-10-19 起使用 InstallerV3.cs + 正式 NSIS 安装包，旧版识别、升级回滚和回归说明见《升级安装说明.md》。build.ps1 现在构建 V3。以下为 V2 历史记录，不代表现行入口行为。

根目录仅提供 `安装白球AI.exe`。它在运行时从同级 `白球AI便携版/app` 读取程序，因此后续便携程序更新后，无需重新打包安装源。`启动白球AI.exe` 仍负责直接运行硬盘上的便携版。

新版为独立 .NET Framework WinForms 程序，无 PowerShell/CMD 依赖，适用于满足白球运行要求的 Windows 电脑。用户可选择安装位置；默认当前用户的 LocalAppData/Programs/白球AI。开始安装后在后台复制到同盘临时目录，逐文件比较 SHA-256，全部通过后替换目标目录，生成桌面及开始菜单快捷方式。旧安装保留为相邻的 `.backup-*` 目录；复制失败不会覆盖旧程序，失败临时目录路径会显示。

不复制移动硬盘 profile、记忆、密钥和浏览器登录状态。现有程序的数据位置遵循白球自身逻辑，本次安装器不迁移数据。安装源必须为真实文件；遇到链接明确停止，不再静默遗漏依赖。当前 F 盘安装源预检没有重解析点。

构建：运行 `build.ps1`，依赖 Windows .NET Framework C# 编译器。源文件 InstallerV2.cs 和 baiqiu.ico 同目录。

隔离回归：将 InstallerV2.cs 与 InstallerTests.cs 一起编译，入口指定 InstallerTests，输出为控制台程序；传入一个全新测试目录，可选第二参数传入 F 盘 app 路径，仅做安装源只读预检。测试不创建真实桌面快捷方式、不安装真实白球、不调用模型。

2026-10-18：测试覆盖真实复制与哈希校验、最新内容升级、旧目录备份、不相关目录保护、磁盘根目录/重叠目录拒绝、源文件锁定失败、目录替换失败回滚、缺文件、链接检测、中文窗口。生产源共 9,333 个文件通过目录及必需文件预检；尚未在其他电脑做完整安装启动验收。
