# KB 回传、等待提示、对话内文件预览

本轮只修改当前测试版源码，不包含重启、构建、发布或运行测试。

## 范围

1. 修正实际累计变量 receivedBytes 与发送字段 bytesReceived 混用导致的 ReferenceError。复用上一轮的真实字节累计、按请求去重和原位数字更新，不将 KB 当作 Token 或完成率。
2. 已知正常运行时等待提示仅用于当前状态行，不再占据三行执行历史。正常上下文/连接提示更新时相互替换；真实阶段回复或正文边界使旧提示退场；真实活动工具优先。原始事件保持完整，失败、重试、工具代码、公开回复不被删除。无等待提示时 KB 使用同一区域的独立计数行。
3. 表格、行内代码中独立的本机文件路径，以及本机 file 链接，可以点击在该回复下方展开预览。保留原 Markdown 数据；不改表格结构。预览外置于流式正文节点，避免正文更新直接覆盖预览。

PDF 使用已有本机 PDF 阅读器；图片按图片展示；Word/PPT 明确标注为内容/文字预览，不声称复刻原始排版。提供打开原文件、打开所在位置、收起操作；每条回复复用一个预览面板，忽略较旧文件读取结果，关闭后不会被迟到结果重新打开。

对话预览按确切绝对路径读取，不按同名文件搜索兜底。不存在、无权限、目录、暂不支持的类型都会明确反馈。不执行 HTML 或代码文件；这些类型只显示文本。非 PDF 文件超过 20 MB 时转为明确提示外部打开；文本超过 12,000 字符明确说明截断。PDF 不先整体读入主进程内存。只有点击时读取文件。
