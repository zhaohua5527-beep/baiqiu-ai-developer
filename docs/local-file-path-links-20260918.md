# 回复中的本地文件路径链接（2026-09-18）

普通回复中的 Windows 本地路径（例如 `D:\\白球AI\\data\\结果.pdf`）会被识别为可点击链接。点击后调用现有 `api.openPath()`，由系统默认程序打开文件；打开失败只显示提示，不修改原回复。

代码块、命令块、已有网页链接和按钮内部的路径不会被转换。路径只在渲染层增加链接表现，文件路径仍来自模型或工具真实输出，不生成虚假路径。

验证：路径链接接入测试 2/2 通过；JavaScript 语法和 diff 空白检查通过；已有答案完成排版检查 12/12 通过。

当前测试窗口检测到中文输入法正在组词且有草稿，因此没有强制刷新，避免丢失输入。空闲后重新加载测试版即可看到新链接。
