# 待补充队列

2026-09-29：运行中普通文字补充的行为已在源代码中改为原生接续，详见 `live-supplements-20260929.md`。本页记录的是原排队版本，以下历史测试结果不能视为新实现已验证。

执行期间提交的内容进入当前会话的“待补充”。前一轮正常完成、结果持久化且可见输出结束后，按顺序发送下一条。模型收到补充语义提示，用户消息保留原文；附件、引用及结构化选择沿用现有发送通道。

运行中点击箭头只调整下一条的优先级，不中断当前请求。编辑在独立对话框完成，保留原附件、引用与选择，且编辑中的队首不会被自动发送。失败、待确认、待配置或主动停止会暂停自动接续，待补充内容仍保留，可点击箭头继续。自动发送不修改输入框内尚未发送的草稿。

每个会话分别维护请求完成和显示完成状态。请求所有权、派发锁及运行 ID 防止重复派发和旧回调释放新请求。发送前持久化失败会恢复队首并暂停。队列沿用当前窗口的内存存储，退出或刷新客户端不会恢复尚未发送的补充；本次未新增跨重启自动执行。
