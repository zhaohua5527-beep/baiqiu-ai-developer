# 黑球自然表情

当前组合为固定圆润球体与透明像素五官，显示尺寸为 28px。在原先五官层缩放 15% 的基础上，分别围绕左眼、右眼、嘴巴各自中心，将图像加宽 50%、增高 30%，避免放大五官间距。所有 15 种表情及闭眼帧位于 `renderer-v2/assets/natural-task-faces`；球体图片独立，不随表情切换。图片禁止拖拽，外层按钮继续支持点击和键盘展开执行记录。

`renderer-v2/task-face.js` 为当前消息列表提供一个动画控制器，优先选择当前正在执行的任务；没有运行任务时选择列表末尾已完成任务。新的活动项取代旧项时清除旧计时器；插入较旧历史记录不会抢占动画。窗口隐藏或当前球体离开滚动视口时暂停，不改为播放上方历史球体。

实时执行事件由 `setLiveStreamActivity` 和 `pushExecutionActivityDetail` 传入装饰层。工具调用和公开思考对应专注，`cross_check` 对应疑惑，工具返回或阶段结果对应浅笑，等待用户输入对应倾听，明确失败对应苦恼。不同任务和已知较旧序号的事件不能改变当前表情，未知事件保持原表情。表情变化不重置眨眼周期，不生成新进度事件，也不从正文推断用户情绪。

新完成事件由 `freezeLiveStreamElapsed` 提供任务标识、真实结束时间和结果状态。成功时显示开心约两秒、浅笑约两秒，然后回到平静；失败、取消、等待分别短暂显示苦恼、小失落、倾听。历史恢复不会重新播放成功动画。预留表情素材不参与无依据的随机轮播。

平静眨眼间隔随机 1.8～3 秒，闭眼 150～200 毫秒，每 2～3 组眨眼中包含一次双眨眼，两次之间睁眼 180 毫秒。双眨眼结束后恢复常规间隔，不连续追加第三次。表情变化不会重新设置正在运行的眨眼间隔。所有动画仅用于装饰，不生成执行事件、不写入聊天内容、不调用模型。

验证：独立浏览器组件检查覆盖运行中眨眼、执行事件表情映射、过期或其他任务事件隔离、成功回应顺序、连续眨眼的时间间隔、固定球体、历史静止、完成接管、隐藏及离屏暂停、切换会话、尺寸和禁拖拽、点击与 Enter。最新脚本保存在客户端工作目录 `work/active-face-20260910/verify.cjs`。未发送模型测试任务。
