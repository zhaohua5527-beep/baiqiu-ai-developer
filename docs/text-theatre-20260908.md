# 文字小剧场重做（2026-09-08）

本次按用户纠正后的需求，替换图形角色版：文字本身就是演员。黑球、孙悟空等角色词语分别运动，BOM～、砰、咻等拟声词在动作发生时出现。恢复文字叙事，不使用 SVG 角色、图形道具或固定六镜头轮播。

## 实现

- `renderer-v2/mini-theatre.js`：保留既有 create/start/finish/select/destroy 接口、每任务单容器和任务生命周期接线。替换本地故事与绘制部分；角色、动作连接词、对方角色、拟声词是独立 DOM，普通文案通过 textContent 写入。
- `renderer-v2/mini-theatre.css`：改为无卡片背景的文字呈现，字体沿用页面字体。角色拥有冲撞、追逐、翻滚、闪避、跳跃、漂浮、震动、击掌、惊喜、休息等动作；拟声词有爆开、抖动、回声三类效果。CSS 仅作用于小剧场。
- `test/mini-theatre.test.js`：替换固定六镜头断言，新增剧情连贯性、随机组合、持续运行和离开收尾画面的释放检查。

剧情由本地模板组合。每段约 6.2—7.6 秒，下一段依赖上一段的结果；记住本章人物、地点和道具，并有争夺、失手、再次尝试、和解、结伴、过桥、开门、续章等分支。新任务避开上一任务的开场角色，续章也可重逢旧角色。内容持续更新，没有原先五段上限；文案池有限，不声称无限生成从未重复的小说。

同一个容器保留上一段的淡化文字和本段动态正文。无需滚动累积剧场日志。结束时词语回到可读位置，显示与真实成功、失败、取消或等待状态对应的收尾，然后冻结并释放计时器；后台完成和切换会话仍受原有任务归属约束。
