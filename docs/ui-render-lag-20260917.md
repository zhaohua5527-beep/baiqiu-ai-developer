## 范围与结论

桌面“白球AI-测试-11”实际运行 source-current Electron 开发版，版本 3.0.25，调试端口 9241，本次采样时主进程 PID 31400。未发布顾客更新包。

已复现执行列表的无效 DOM 刷新及隐藏事件逐字动画。它们占用与输入法共用的渲染线程，是可以确认的性能缺陷；尚不能据此认定所有任务停顿、接口等待或超时均由此造成。

## 修复

- `paintExecutionStageView` 原先无条件重设历史行内容、replaceChildren 整段执行列表，并将已经置于交叉回复时间线的节点先搬回再搬出。改为复用未变行，仅在顺序变化时移动节点，保留选中文字和时间线节点归属。
- 已折叠执行行的逐字动画直接完成到收到的全文，保留所有事件和展开内容，不再让不可见的几百行持续争抢动画帧。
- 溢出测量集中在同一帧，先读取尺寸再写属性，避免每个字符变化分别触发布局。
- interrupted 与 completed 均结束该行逐字播放并保留已接收全文。

未修改请求、工具权限、模型推理、超时策略、事件生产或落盘语义。
