# 3.0.28 稳定性修复与回归记录

## 本轮修复

本轮针对实际运行的 F 盘 3.0.28，修改四个程序文件，并刷新完整性清单。保留当前页面布局、事件通道、快捷启动、用户设置和记忆目录。

| 根因 | 修复 | 验证 |
| --- | --- | --- |
| ACP 收尾先处理协议恢复失败，覆盖了真实取消状态 | 以同一任务的原生取消状态为准，保留阶段结果和正文 | 协议恢复、取消持久化及整机停止按钮回归 |
| 运行账本在磁盘写入成功前就变更内存终态；重复收尾可能影响后续运行 | 先原子持久化，再提交内存终态；旧记录重复收尾返回自己的快照 | 写盘失败重试、重复收尾、后续任务不受影响 |
| 主流程处理格式异常时，漏传已经收到的结构化阶段结果 | 将实际阶段事件交给原生完成凭证的内容哈希校验，通过才标记为已交付但格式降级 | 正确阶段哈希、错误哈希、正文哈希、无答案及普通回答 |
| Chromium 布局通知告警只有 `event.message` 时被误认为致命异常 | 精确识别两种 ResizeObserver 通知告警；真正的类型错误仍报错 | 错误事件、Promise 拒绝、真实类型错误、Electron 实机 |

运行账本仍允许同一用户任务内部的多次模型调用。每次原生调用使用独立事件身份；不能通过禁止复用用户 turnId 来保护终态，否则会破坏工具结果接续。回归覆盖原生桥接连续两次调用及旧记录晚到收尾。

如果电脑关机或拔盘使等待脚本退出，暂存文件仍保留。退出白球后可运行更新目录内 `apply.ps1` 完成覆盖。若版本文件已被其他更新更改，旧哈希校验会拒绝覆盖。
